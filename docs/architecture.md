# Architecture

PRIMA generates verifiable evidence of existence and integrity for a digital
file. It is not an intellectual property registry, does not prove authorship,
and does not replace a lawyer or notary: it proves that a specific file
existed, in a specific state, at a specific point in time.

## Components

- **API + web portal** (`src/api/`, FastAPI, server-rendered pages): the
  public entry point for a human. Confirms the person's email before showing
  the registration form, applies bot protection (Turnstile, honeypot,
  minimum fill time) and rate limits, and exposes a JSON API consumed by the
  static frontend (`frontend/`).
- **MCP entry** (`src/api/mcp_entry.py`): a separate, lower-friction entry
  point for an agent (see "MCP server" below) instead of a human filling a
  form. Same evidence pipeline underneath.
- **Worker** (`src/worker.py`, `src/core/ots_worker.py`): background process
  that requests the OpenTimestamps proof, polls Bitcoin for the anchor,
  generates the certificate once the timestamp is confirmed, and queues
  notifications.
- **MCP server** (`fragola_mcp/`): a Model Context Protocol server with
  `prima_*` tools, so an LLM agent (Claude or any MCP client) can register
  and track evidence on behalf of a person, talking to a running PRIMA
  server over its public API.
- **Independent verifier** (`fragola_mcp/verify/prima_verify.py`): a
  standalone script with no dependency on PRIMA. Given a certificate
  package and (optionally) the original files, it recomputes every hash,
  checks the timestamp proof, and — with `--online` — checks the Bitcoin
  block header directly, without trusting PRIMA's word for it.

## Evidence pipeline

1. **Manifest**: a canonical JSON document (`src/core/manifest.py`,
   public schema at `fragola_mcp/schema/prima-manifest-1.0.schema.json`)
   listing the evidence's metadata and, for each file, its SHA-256
   fingerprint. The manifest is serialized deterministically (sorted keys,
   no extra whitespace) so its own hash is reproducible by anyone.
2. **Timestamp**: the manifest's hash is submitted to OpenTimestamps
   (`src/core/ots.py`), which returns a proof that a transaction containing
   that hash was accepted into a Bitcoin block.
3. **Certificate**: once the Bitcoin anchor is confirmed, a PDF certificate
   is generated (`src/core/certificate.py`) and packaged with the manifest,
   its hash, and the OpenTimestamps proof into a ZIP the person keeps.
   Original files are not kept by the server by default
   (`PROOF_STORE_ORIGINALS=false`): only their fingerprint is computed.
4. **Verification**: anyone, at any time, with just the ZIP package and
   (to check a specific file) the original, can confirm the whole chain
   without asking PRIMA anything — either manually against
   `https://opentimestamps.org`, or with `prima_verify.py --online`.

## FAIR implementation

Developed following FAIR principles (FAIR4RS), not "FAIR-certified":

- **Findable**: JSON-LD (schema.org) metadata generated by the MCP for each
  registered project; `CITATION.cff`, `codemeta.json` and `.zenodo.json`
  for discovery and citation.
- **Accessible**: static OpenAPI 3.1 description of the public API
  (`fragola_mcp/schema/prima-api.openapi.json`); the independent verifier
  does not require access to PRIMA at all.
- **Interoperable**: the manifest follows a public JSON Schema; the API is
  documented in a standard, machine-readable format.
- **Reusable**: Apache-2.0 license, this repository publishes the server
  itself (not only a client wrapper), and the installation guide
  (`docs/installation.md`) covers running it on your own infrastructure.
  Full parity is not claimed: this release does not include the
  notification workflow (see `CHANGELOG.md`).
